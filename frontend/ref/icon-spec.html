Electron build pipeline

一张 1024 PNG → 全平台格式

项目里已经写好了 build-icons.sh —— 用 macOS 自带的 sips 和 iconutil 生成 .icns ；如果装了 ImageMagick 也会顺便出 .ico 。不需要 electron-icon-builder。

1. 准备透明底主图

当前 png 外部是纯白。先用 ImageMagick 把白底抠成透明（或者 在 Preview 里 instant alpha），再喂给打包脚本 —— 蓝色信封 的边缘光辉在透明底上才显得「漂浮」而不是被白框框死。 

# 1) 抠掉白底 → icon-1024.png（透明）
# 方法 A：装了 ImageMagick
magick mailagent_logo.png \
  -fuzz 5% -transparent white \
  -resize 1024x1024 \
  icon-1024.png

# 方法 B：纯 macOS 工具
sips -s format png \
  -z 1024 1024 \
  mailagent_logo.png \
  --out icon-1024.png
# 然后 Preview.app 打开 → 选取 → Instant Alpha
# 点白色区域 → delete → ⌘S

2. 一键打包

脚本会在 ./build/ 下产出 icon.icns / icon.ico / icons/{16…1024}.png。 

# 2) 跑脚本
./build-icons.sh icon-1024.png

# 产出
build/
├── icon.icns         # macOS — Dock / Finder
├── icon.ico          # Windows — taskbar / .exe
└── icons/
    ├── 16.png   32.png   64.png
    ├── 128.png  256.png  512.png
    └── 1024.png

3. electron-builder 配置

打包脚本产出的文件名和 electron-builder 默认期望一致， 写在 package.json 或 electron-builder.yml 里： 

{
  "build": {
    "appId": "com.mailagent.app",
    "productName": "MailAgent",
    "mac": {
      "icon": "build/icon.icns",
      "category": "public.app-category.productivity"
    },
    "win": {
      "icon": "build/icon.ico"
    },
    "linux": {
      "icon": "build/icons"
    }
  }
}

4. 开发期窗口图标（可选）

BrowserWindow 的 icon 选项只在 Linux / Windows 上生效；macOS 用打包后的 .icns 。开发期想看到 Dock icon 改对，最简单是写一个 app.dock.setIcon() ： 

// main.ts
import { app, BrowserWindow, nativeImage } from 'electron';
import path from 'node:path';

app.whenReady().then(() => {
  // dev Dock icon (macOS only)
  if (process.platform === 'darwin') {
    app.dock?.setIcon(
      nativeImage.createFromPath(
        path.join(__dirname, '../build/icons/512.png')
      )
    );
  }

  const win = new BrowserWindow({
    width: 1200,
    height: 800,
    icon: path.join(__dirname, '../build/icons/512.png'),
  });
});

FAQ

需要哪些格式？

macOS — .icns 必需

.app bundle 必须用 .icns ，否则 Dock / Finder / Spotlight 会回退到通用文件图标。 脚本里 iconutil 已经处理好了。

Windows — .ico 建议

即使只发 macOS，也建议生成 .ico —— 文件只有几十 KB，未来出 Windows 版不用重做。 脚本会自动跳过（如果没装 ImageMagick）。

Linux — PNG 集

.deb / .AppImage / .rpm 用多尺寸 PNG 目录。electron-builder 指向 build/icons/ 即可。

灵动岛 / 通知中心？

都用同一张主图 —— 灵动岛会自动 mask 成圆形（环形光轨 会被裁掉边缘一小圈），通知中心会自动加圆角。如果想在 灵动岛上做更克制的版本，可以单独导出一个只保留信封剪影、 去掉光环的 SVG。
