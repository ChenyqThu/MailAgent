MailAgent · Ping Island plugin

v4 · patch on ping-island
upstream · erha19/ping-island

MailAgent 不自己渲染灵动岛。直接复用开源的 Ping Island（Apache-2.0 · macOS 菜单栏应用 · 已支持 12+ 编码 Agent），通过它的官方 hook 协议把邮件事件喂进去 — Ping Island 的 notch UI 负责渲染。 MailAgent 这一侧的贡献只有 4 件事：邮件事件 → Ping Island event 的翻译层 · 3 只专属 mascot · "跳转邮件" deep-link handler · buddy-detach 时显示未读计数。

§1 · 集成架构

两个进程 · 一条 unix socket · 零 UI 重复

Ping Island 是独立的 macOS App（用户走 brew 或 DMG 安装），MailAgent.app 是另一个独立 Electron 进程。 两者通过 Ping Island 已有的 hook plugin 机制对接 — MailAgent 安装时往 ~/.mailagent/plugins/ping_island/ 写一份配置和一个轻量 bridge 脚本，Ping Island 启动时自动发现并加载。 不需要 fork Ping Island 源码，也不需要发布定制版本。

§4 · 事件映射表

MailAgent → Ping Island canonical events

Ping Island 把所有 Agent 事件归一化成 5 类（来自它的音效引擎事件 schema）：task.acknowledge · input.required · task.complete · task.error · resource.limit。MailAgent 只需要把自家事件投射到这 5 个槽里 — 它的 UI / 音效 / 路由就免费拿到。

MailAgent event → Ping Island category Phase 1 (arrive) Phase 2 (rest pip) 默认动作 mascot pip
mail.arrived (Critical) task.acknowledge ● ● Open · Snooze crit (pulse)
mail.arrived (Urgent) task.acknowledge ● ● Open · Snooze urg
mail.arrived (Important) task.acknowledge ● — flash 2.5s · 不留 pip —
mail.arrived (Normal / Low) — — — 完全不进岛 —
ai.draft.ready input.required ● ● 发送 · 编辑 · 重生成 ai
ai.ask.user input.required ● ● ⌘1 / ⌘2 / ⌘3 选答 ask
sync.complete (batch) task.complete ● — "Done — click to jump" 2s ok
sync.failed (≥1 dead-letter) task.error ● ● Retry · Open /admin fail
llm.budget.warning resource.limit ● — flash · 打开 /llm 看板 —

§5 · 安装契约

MailAgent 设置页 → 启用 Ping Island 集成

用户开关一打开，MailAgent 检测到本机有 /Applications/Ping Island.app 后，往 ~/.mailagent/plugins/ping_island/ 写一份配置 + 一个 bridge 脚本。Ping Island 启动时按它的 plugin 协议自动发现 — 不需要用户改 Ping Island 设置。

directory layout
~/.mailagent/plugins/ping_island/
├── manifest.json      # registration with Ping Island
├── bridge.py          # socket → hook event translator
├── mascots/           # 3 × 36px GIF
│   ├── postman.gif
│   ├── pidgeon.gif
│   └── devbot.gif
└── sounds/            # optional pack
    ├── openpeon.json
    ├── mail-arrived.wav
    └── sync-failed.wav
manifest.json
{
  "plugin_id":    "mailagent",
  "display_name": "MailAgent",
  "version":      "1.0.0",
  "socket":       "unix:///tmp/mailagent.sock",
  "mascots": {
    "work":     "mascots/postman.gif",
    "personal": "mascots/pidgeon.gif",
    "dev":      "mascots/devbot.gif"
  },
  "deep_link_scheme": "mailagent",
  "jump_template":    "mailagent://open?id={id}",
  "event_categories": [
    "task.acknowledge",
    "input.required",
    "task.complete",
    "task.error",
    "resource.limit"
  ]
}

§6 · Bridge 协议

事件载荷的形状

mail-sync daemon 把这个形状的 JSON 推到 /tmp/mailagent.sock，bridge.py 读取后翻译成 Ping Island 期望的 hook event 格式发到 Ping Island 的内部端口。反向（"我点击了"）走 macOS deep-link scheme，无需再开一条 socket。 

// MailAgent → Bridge (向上推)
type MailAgentEvent =
  | { kind: 'mail.arrived',    id: string, account: AccountId,
      priority: 'critical' | 'urgent' | 'important' | 'normal' | 'low',
      subject: string, from: string, snippet: string, tag?: string }
  | { kind: 'ai.draft.ready',  id: string, mail_id: string,
      model: string, tokens: number, cost_usd: number, preview: string }
  | { kind: 'ai.ask.user',     id: string, mail_id: string,
      question: string, choices: string[] /* 2-4 */ }
  | { kind: 'sync.complete',   batch_size: number, duration_ms: number }
  | { kind: 'sync.failed',     dead_letter_count: number, last_error: string }
  | { kind: 'llm.budget.warning', used_usd: number, budget_usd: number }
  | { kind: 'accent',          value: AccentName }; /* theme sync */

// Bridge → MailAgent (向下回调) — via macOS URL scheme handler
// mailagent://open?id=<mail_id>
// mailagent://action?id=<event_id>&action=send|edit|snooze|retry
// mailagent://answer?id=<event_id>&choice=<index>

§7 · Buddy 离岛

长按刘海 · 向上拖出 · 悬浮陪伴

Ping Island v0.5.0+ 支持把当前 mascot 从刘海里拖出来，作为独立 floating window 一直在桌面上。MailAgent 这一侧不写代码 — 但在 mascot 上贴一个未读邮件 counter，让它从"装饰"变成"一直能看见的实时提示"。

点击 buddy → 打开 MailAgent 主窗口 · 双击 → 触发"标记所有为已读"
MailAgent 这一侧只贡献两件事 · ① 把"未读总数"作为 metadata 推给 Ping Island · ② 在 manifest 里声明 buddy_double_click: "mark.all.read"。其他全部用 Ping Island 的原生离岛能力。

§8 · 规格表

MailAgent 实现侧需要遵守的硬约束
Sizing
  • Mascot GIF — 36 × 36, transparent bg, ≤ 12 KB
  • Title — ≤ 36 字符（含中文计 2）
  • Subtitle — ≤ 60 字符
  • Tag — 单 tag · ≤ 12 字符
  • Preview — ≤ 4 行 · ≤ 240 字符
Motion
  • 由 Ping Island 控制
  • arrive hold = 4 s（不要在 event 里覆盖）
  • Important flash = 2.5 s · 不留 pip
  • complete "click to jump" 提示 = 2 s
  • 动作按钮反馈 ≤ 150 ms
Keyboard
  • ⌘⏎ — open focused
  • J / K — 切 focused
  • ⌘E — secondary action (edit / retry)
  • ⌘. — snooze
  • ⌘1–⌘4 — answer ask choices
  • ⌥I — 强制展开岛（Ping Island 内置）
Routing
  • click row → mailagent://open?id=
  • click 主按钮 → mailagent://action?...
  • click pip → 等同 click row
  • click buddy → 主窗口聚焦
  • 双击 buddy → mark.all.read
主题色与 inbox 共享
MailAgent 设置页改色 → bridge 推一条 { kind: 'accent', value } → Ping Island 在 MailAgent 自己渲染的部分（draft block / AI badge / 主按钮 ring）跟着变 · 面板黑底不变。
