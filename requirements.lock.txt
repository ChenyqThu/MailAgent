# 生成方式（2026-07-02）：对已 provision 的嵌入式 venv 直接 pip freeze（锁定现状，非解析 PyPI 最新）：
#   venv/bin/python -m pip freeze --path frontend/resources/python/lib/python3.11/site-packages
#   （排除 "mailagent @ file://..." 一行）

# 更新方法：升级/增删依赖 = 改 requirements.txt 或 pyproject.toml 后，在干净 Python 3.11 环境重新解析：
#   python3.11 -m venv /tmp/relock && /tmp/relock/bin/pip install -r requirements.txt \
#     && /tmp/relock/bin/pip install ".[cli,api,memory]" \
#     && /tmp/relock/bin/pip freeze | grep -v '^mailagent' > requirements.lock.txt
#   然后恢复本文件头注释、提交 lock diff。🔴 只改 requirements.txt/pyproject 不重新生成 lock
#   = 改动不进包（provision 只认本文件）。

#   其余上百个包一并升到 PyPI 最新，那与本文件「锁定现状」的目的相反，且把一次加包的
#   diff 放大成上百行、每一行都是未经验证的版本跳变。判据是「pip install 该包时输出的
#   Installing collected packages 只有它自己」。已按此例外增量加入的包：
