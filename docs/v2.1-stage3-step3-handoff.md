## 2. step 3-6 计划（六步，每步独立可验）

### step 3 — 定义 `ChatPlatform` 接口（`shared/chat/platform.ts`）
按设计文档 §3 落接口（persist / loadEmailContext / llmFetch / notionAgentStream / tools / saveToKos / getCachedSenderDigest / prefetchSenderDigest / resolveConfig）。**D1 关键**：persist 拆 `streamContent`(debounced, fire-and-forget) + `finalizeMessage`(awaited 终态)，cadence 进 platform（electron 同步直写、http debounce）。纯接口文件，零运行时依赖。

### step 4 — 搬 `harness.ts` → `shared/chat/harness.ts`
**外部调用→platform 映射**（这是核心改动，逐一路由）：
| harness 当前 import | 用途 | 改成 |
|---|---|---|
| `../chat_db`: `updateMessage`(每 chunk) | 流式正文持久化 | `platform.persist.streamContent(msgId, buffer)` |
| `../chat_db`: `updateMessage`(终态 complete/error) | 终态落库 | `platform.persist.finalizeMessage(msgId, patch)` |
| `../chat_db`: `appendToolCall` / `getToolCallByUseId` / `updateToolCall` / `abortStreamingMessages` | 工具审计 + abort | `platform.persist.*` |
| `../chat_db`: `type ChatMessage` / `type ConfirmationTier` | 类型 | `@shared/chat/model` |
| `./config`: `getMaxIter` / `getMaxCostUsd` / `isKosL1HotBlockEnabled` | 配置 | `platform.resolveConfig()` 快照（harness 启动时取一次） |
| `../kos/sender_digest_cache`: `prefetchSenderDigest` | L1 hot block | `platform.prefetchSenderDigest(addr)` |
| `@shared/chat/tools/*` + `@shared/chat/types` | — | 已在 shared，不变 |
- `args.sink`（HarnessSink）+ `args.registry`（ToolRegistry）已是注入式 → 保留注入（registry 由 platform 提供 = 工具绑定 platform.tools 或 Electron handlers）。
- `args.backend`（ChatBackend）已注入。
- 既有 harness 单测改驱动 shared harness + mock platform。

### step 5 — 搬 `dispatcher.ts` → `shared/chat/dispatcher.ts`（逻辑部分）+ ElectronChatPlatform（main）
**dispatcher 外部调用→platform 映射**：
| dispatcher 当前 import | 用途 | 改成 |
|---|---|---|
| `electron`: `WebContents`(type) + `makeWebContentsSink` | IPC fanout sink | sink 工厂**留 main**；shared dispatcher 收注入 sink |
| `../chat_db`: `appendMessage`/`getOrCreateSession`/`getSession`/`getMessage`/`listLastNMessages`/`deleteMessagesFromId`/`updateMessage`/`abortStreamingMessages` | 会话+消息 CRUD | `platform.persist.*` |
| `../db`: `getDb`（loadEmailContext raw SQL） | 邮件上下文 | `platform.loadEmailContext(emailId)` |
| `./backends/notion_agent_gate`: `drainNotionAgentGate` | 串行门 | **留 main**（notion-agent 专属）→ platform 或 main 适配 |
| `./config`: `backendSupportsTools` / `isHarnessEnabled` | gate | `platform.resolveConfig()` |
| `./registry`: `getChatBackend` | 后端注册表 | backend 注入 / platform 提供 |
| `@shared/chat/tools/confirmation` + `@shared/chat/types` | — | 已 shared |
- **`ElectronChatPlatform`（`src/electron/main/chat/electron_platform.ts`，非 shared）**：实现 ChatPlatform，**直调既有 chat_db/db/handlers/llm_settings/kos**（`streamContent` = 同步 `updateMessage`，零回归）。
- `handlers/chat.ts` 改用 ElectronChatPlatform 构造 dispatcher/harness + 仍用 makeWebContentsSink。
