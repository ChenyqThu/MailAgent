## 3. cutover 重点（务必留意，这是 3c 改造的核心）

- [ ] **流式 token 直驱 React**：cutover 后 harness 在 renderer 同进程跑，token 经进程内 emitter 直驱（无 IPC 推流）→ 流式应顺滑、**无重复投递**（旧 IPC 泄漏 bug 的特征是整段重复，见 memory `reference_electron_ipc_subscribe_leak`）
- [ ] **写工具确认 = 同进程**：ConfirmToolDialog 弹窗 → 确认 → 同进程 resolveConfirmation（非 IPC 往返）→ 应即时响应
- [ ] **本地打包态 file:// CORS 腿**（首次真机验证）：本地 app renderer 是 `file://`（Origin null），chat 能跑 = `chat_local_bridge` webRequest 注 token + CORS 生效
- [ ] **远程 CF cookie 鉴权**：远程能跑 chat = CF cookie 鉴权腿生效
- [ ] **「AI 未配置」边界**：若某后端 key 没配，应 graceful 提示（toast，**不白屏 crash**）
