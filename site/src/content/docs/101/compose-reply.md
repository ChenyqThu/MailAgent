收到一封需要回信的邮件，MailAgent 能帮你省掉"从空白开始写"这一步：AI 先读完整封邮件、给出一份可直接编辑的草稿，你润色后再发出。这一节讲清楚怎么起草、三种回复方式的区别，以及草稿最终落到哪里。

## 一眼看懂

| 想做的事 | 怎么做 |
|---|---|
| 让 AI 帮我写回复 | 选中邮件，按 `R` |
| 只回复发件人 | 撰写面板顶部切到「回复」 |
| 回复所有人（含抄送） | 切到「回复所有人」（默认） |
| 转发给别人 | 切到「转发」，填收件人 |
| 回复写成中文 / 英文 | 撰写面板里点「翻译」一键互译 |
| 把草稿发出去 | 点「发送」 |

## 用 AI 起草一封回复

1. 在收件箱里选中要回复的邮件。
2. 按 `R`（或点详情区顶部的 **回复** 按钮）。
3. 撰写面板从详情区上方展开，正文里已经填好了 AI 建议的回复内容。
4. 按需修改 —— AI 给的是初稿，不是终稿，**发出前请通读一遍**。
5. 确认无误后点 **发送**。

:::note[AI 草稿从哪来]
AI 建议的回复正文存在本地数据库里（每封邮件经 AI 处理后会生成一份回复建议）。按 `R` 时 MailAgent 读的就是这份建议 —— **包括你之前改过的版本**。所以同一封邮件第二次起草，会接着上次的编辑继续，而不是从头再生成。
:::

如果某封邮件没有 AI 建议（比如还没被 AI 处理、或是一封纯通知类邮件），撰写面板依然会打开，只是正文为空，你可以自己写。

## 回复 / 全部回复 / 转发

撰写面板顶部有三种模式，对应日常最常用的三种动作：

| 模式 | 收件人 | 适用场景 |
|---|---|---|
| **回复** | 仅原发件人 | 只需私下答复对方一个人 |
| **回复所有人** | 原发件人 + 原 To/CC（自动去掉你自己） | 群发讨论里需要让所有相关人看到（默认） |
| **转发** | 需你手动填收件人 | 把这封邮件交给本来不在收件人列表里的人 |

- 「回复」和「回复所有人」会**自动带上原文引用**，保留完整的往来上下文，对方一看就知道你在回哪条。
- 「转发」正文是原邮件内容，你在上方补一句说明即可。
- 「回复所有人」会**自动把你自己的邮箱从收件人里剔除**，不会出现"回信给自己"。

:::tip[临时加收件人 / 抄送]
即便用「回复」或「回复所有人」，你也可以在撰写面板里手动补充额外的收件人（To）或抄送（CC），不影响原有的自动收件人逻辑。
:::

## 写回复时一键翻译

如果对方用英文写来、而你想用中文起草（或反过来），不用切到别处：撰写面板里点 **翻译**，正文会在中英之间互转。常见用法：

- AI 给了一份英文草稿，你先用中文把意思理顺、改完再点翻译转回英文发出。
- 收到中文邮件，但需要用英文回复给海外同事。

翻译在**撰写面板内部**完成，和收件箱里对整封来信的「一键翻译」（`T` 键）是两件事：前者翻译你正在写的回复，后者翻译别人发来的邮件。

## 草稿最终去哪了

点「发送」后，邮件经当前的邮件后端发出：

- **DavMail 模式（生产主路径）**：草稿通过 IMAP 写入 Exchange 草稿箱、经 SMTP 发出。Exchange 账户的草稿会自动同步到 Outlook，你在手机、网页版 Outlook 上都能看到。
- **AppleScript 模式（备用路径）**：草稿在 Mail.app 里创建为真正的回复（保留完整线程历史），需要 Mail.app 窗口短暂弹出约 3 秒来完成。

:::caution[关于自动归档到「已发送」]
是否把发出的邮件自动归入「已发送」由开关 `davmail_archive_sent` 控制，默认关闭。如果你发现发出的邮件没出现在「发件箱 / 已发送」里，多半是这个开关没开 —— 这是预期行为，不是丢件。
:::

:::note[EWS 关停提醒]
DavMail 当前通过 EWS（Exchange Web Services）桥接 Exchange。微软已宣布 **EWS 将于 2026-10-01 关停**，届时 DavMail 6.7 的当前路径将不可用。迁移方案（改走 Microsoft Graph API）详见 `docs/reference/architecture/roadmap-post-cutover.md` §5.1。AppleScript 备用路径不依赖 EWS，始终可用。
:::

## 常见疑问

- **草稿创建后正文是空的 / 收件人不对？** 多半是邮箱后端配置（账户名、邮箱名）有偏差，先到设置里核对，或参见[故障排查](/101/troubleshooting/)。
- **想取消刚起草的回复？** 直接关闭撰写面板即可，未发送的草稿不会留下。
- **AI 草稿质量不满意？** 它是基于邮件正文 + 线程上下文生成的初稿，把它当起点，编辑后再发 —— 你的修改还会被记住，供下次起草复用。
