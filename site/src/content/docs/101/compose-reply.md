写一封新邮件、回复一封来信、转发给别人——这些动作共用同一个撰写面板。这一节讲清楚怎么触发、面板里有什么，以及草稿最终存到哪里。

## 一眼看懂

| 想做的事 | 怎么做 |
|---|---|
| 写一封新邮件 | `⌘N`，或点侧边栏「写邮件」 |
| 只回复发件人 | 邮件详情页点「回复」 |
| 回复所有人（含抄送） | 点「回复」旁的展开箭头，选「回复所有」 |
| 转发给别人 | 点展开箭头，选「转发」，填收件人 |
| 让 AI 帮我起草 | 打开撰写面板时，正文会自动带上 AI 建议的回复内容（如果这封邮件已被 AI 处理过） |
| 把草稿发出去 | 点「发送」 |

## AI 起草的回复从哪来

MailAgent 对每封已处理的邮件都会生成一份回复建议，存在本地数据库里。点「回复」打开撰写面板时，正文会直接带出这份建议——**包括你之前改过的版本**，所以同一封邮件第二次打开撰写面板，会接着上次的编辑继续，而不是从头再生成一次。如果某封邮件还没有 AI 建议（比如还没被处理，或是一封纯通知邮件），撰写面板依然会打开，只是正文为空，你可以自己写。

按需修改——AI 给的是初稿，不是终稿，发出前请通读一遍。

## 回复 / 回复所有 / 转发

| 模式 | 收件人 | 适用场景 |
|---|---|---|
| **回复** | 仅原发件人 | 只需私下答复对方一个人 |
| **回复所有** | 原发件人 + 原 To / CC（自动去掉你自己） | 群发讨论里需要让所有相关人看到 |
| **转发** | 需你手动填收件人 | 把这封邮件交给本来不在收件人列表里的人 |

「回复」和「回复所有」会自动带上原文引用，保留完整的往来上下文；「转发」正文是原邮件内容，你在上方补一句说明即可。

:::tip[临时加收件人 / 抄送]
即便用「回复」或「回复所有」，也可以在撰写面板里手动补充额外的收件人或抄送，不影响原有的自动收件人逻辑。
:::

## 收件人：chip 与通讯录补全

收件人以 chip 的形式呈现，输入时会从[通讯录](/101/contacts/)里补全姓名与所在组织；改过名字、合并过的联系人显示的是整理后的名字，只在通讯录里存在（比如从组织关系推出来）而没有往来记录的人也能搜到。通讯录之外的地址仍然可以手工输入。粘贴多个地址会自动拆分成多个 chip。

## 富文本编辑器

工具栏支持：标题（正文 / 标题 1-3）、字体与字号、加粗 / 斜体 / 下划线 / 删除线、文字颜色与高亮、有序 / 无序列表、引用块、代码块、链接、行内代码、分割线、表格（插入、增删行列、合并 / 拆分单元格）、@ 提及联系人、撤销重做。正文也支持 `/` 快捷插入常用块。

- **行距**：撰写时选的行距会内联写入发出的 HTML，收件方看到的排版与你写的时候一致；默认行距可以在设置 → 通用里调整。
- **链接**：选中一段文字后粘贴网址，会直接把它变成链接。
- **图片**：从剪贴板粘贴或直接拖拽图片，会按光标所在位置插入正文；超过大小上限的图片会提示改用附件发送。

## 附件

工具栏「附件」按钮或直接把文件拖进撰写面板都能添加附件；转发邮件时，原邮件的附件会自动带过来，也可以在发出前移除。

## 草稿：本地优先保存

保存草稿是本地优先的：点保存或自动保存触发时，本地状态立即更新，随后再由后台把内容异步写入邮箱的草稿箱，不需要等这一步网络往返完成。草稿关闭撰写面板不会丢失未保存的内容——如果有未保存的修改，关闭前会提示保存、丢弃或取消。

草稿最终经当前的邮件后端落地：

- **DavMail 模式（生产主路径）**：草稿通过 IMAP 写入 Exchange 草稿箱，经 SMTP 发出。Exchange 账户的草稿会同步到 Outlook，手机、网页版 Outlook 上也能看到。
- **本机 Outlook 模式（Windows）**：直接通过本机安装的 Outlook 收发，不经过 DavMail 中转。

:::caution[关于自动归档到「已发送」]
是否把发出的邮件自动归入「已发送」由一个开关控制，默认关闭。如果发出的邮件没出现在「发件箱 / 已发送」里，多半是这个开关没开——这是预期行为，不是丢件。
:::

:::note[EWS 关停提醒]
DavMail 目前经 Exchange Web Services（EWS）桥接 Exchange。微软计划自 **2026-10-01** 起默认阻断 EWS，2027-04-01 完全退役。迁移进展详见 [`roadmap-post-cutover.md`](https://github.com/ChenyqThu/MailAgent/blob/main/docs/reference/architecture/roadmap-post-cutover.md) §5.1。
:::

## 常见疑问

- **草稿创建后正文是空的、收件人不对？** 多半是邮箱后端配置有偏差，先到设置里核对，或参见[故障排查](/101/troubleshooting/)。
- **想取消刚起草的回复？** 直接关闭撰写面板，选择「丢弃」即可。
- **AI 草稿质量不满意？** 它是基于邮件正文与线程上下文生成的初稿，把它当起点，编辑后再发——你的修改还会被记住，供下次打开这封邮件的撰写面板时复用。
