MailAgent 里会自动做事的 Agent，都收在团队页：主 Agent 有自己的名字与头像；日报、周报、搜索、AI 邮件预处理、项目周报同步这五个内置 Agent；再加上你自己创建的自定义 Agent。想看某个 Agent 平时都在做什么、改它的触发条件或权限范围，来这里。

## 团队页怎么看

左侧是成员清单，分「内置」与「自定义」两组，可以折叠，折叠状态会记住。选中一个成员，右侧是它的记录时间线——会话与执行按时间穿插排列。

每一条执行记录本身就是一份完整的对话：触发、思考、调用工具、交出成果，按时间展开，可以像看普通对话一样往下翻。产出了报告的执行，能在记录详情里直接展开报告全文，默认折叠、展开时才加载。每条记录都标出触发来源与触发时刻——手动、定时、排程、收信、日程变动、会前提醒。

事项跟进也在团队页出现，但它按事项走：对话在具体那件事的页面里开，执行记录也记在那件事的时间线上，团队页上的「事项跟进」只是一个入口。详情见[事项](/101/matters/)。

## 主 Agent 的名字与头像

默认的对话对象——主 Agent——可以起名字、配头像。名字会出现在「XX 思考中…」这类状态提示与对话面板标题上。主 Agent 还有一份可编辑的身份文档，决定它的语气与行事边界，改动在下一次对话里生效；详见 [AI 对话](/101/ai-chat/) 的「记忆与身份文档」一节。

## 内置 Agent

五个内置 Agent 出现在「内置」分组里，可改的项按类型不同：

| 类型 | 可以改什么 |
|---|---|
| 报告（日报 / 周报 / 月报） | 排程、模型、Prompt、回看窗口、带正文的优先级 |
| 搜索 | 模型、Prompt |
| AI 邮件预处理 | 模型、Fallback 备用模型、注入的身份文档勾选、参考上下文源、处理后是否自动标已读、分类 Prompt 全文（收件箱与发件箱各一份，直接编辑，保存即生效） |
| 项目周报同步 | 触发规则 |

改不动的字段不会出现在配置面板里——比如 AI 邮件预处理的总开关实际在 设置 → AI，不在这张配置卡上。所有内置 Agent 的修改都需要人工确认，不能设为自动执行。

## 创建自定义 Agent

四种方式，任选一种：

- **表单**——团队页点「新建智能体」，逐项填名字、用途、模型、触发器与能力范围。
- **在对话里描述**——直接告诉主 Agent 你想要一个什么样的 Agent，它会补问触发时机与能力范围，确认后建成。
- **用模板**——出厂四个模板：会前准备、邮件摘要、跟进追踪、会议速记，一步创建带好触发器与能力的 Agent，再改改细节就能用。
- **导入 Agent 插件**——导入的 Agent 一律以停用状态创建，需要你确认后再启用；配置里引用了本机没有的技能、连接或模型时，导入仍会成功，只是会列出没满足的依赖。

在对话里创建或修改 Agent，审批卡会展示改动前后的对比。这类修改和「创建与修改自定义 Agent」一样恒需确认，见[权限与审批](/101/approvals/)。

## 触发器

一个 Agent 可以配多个触发器，触发器之间是「或」的关系——命中任意一条就跑一次；每条触发器可以单独启停，新增的触发器默认不启用，方便先手动测试再正式打开。单条触发器内部，多个条件是「且」的关系。

触发方式：

- **排程**——点选而不是记 cron 表达式：每 N 天 / 每 N 周（可多选星期几）/ 每 N 月（几号，或「第几个周几」），再加一个时刻。界面会用一句话复述你选的是什么，并列出接下来几次的真实运行时间；月末落不到某个日期时，跳过还是顺延到月末由你选。
- **邮件事件**——按发件人、主题（正则）、文件夹或线程 ID 过滤。从邮件详情菜单选「为此线程建立跟进 Agent」，可以直接带着当前线程的条件进新建表单。
- **日历变化**——日程的业务字段（新建、标题、组织者、参与人、地点或会议链接、议程正文、取消状态）发生变化时触发；单纯改动起止时间不算。
- **会前**——会议开始前若干分钟、小时或天触发，默认提前一天，可以按标题、组织者、参与人或日历名称进一步过滤。

## 能力卡与逐工具微调

创建或编辑 Agent 时，权限按用途分成几张能力卡，每张卡内是一个档位（关闭 / 只读 / 更高权限），不需要先去记住某个工具的名字：

邮件（读取 / 整理 / 起草）、日历（关闭 / 读取 / 写入，写操作恒需确认，不能配免卡规则）、知识（身份文档、Skill 与知识库）、会话（只读自己的历史 / 读全部 Agent 的历史）、报告（读取 / 产出）、Web（关闭 / 域名门控 / 全开放）、命令与本机文件、外部服务（关闭 / 只读 / 读 + 新建 + 修改）、资料库（关闭 / 只读 / 可写，可写限于「Agents 文档」和被设为可写的挂载目录，不含「我的文档」）。

需要更细的控制，展开「高级」折叠区逐工具勾选；这时能力卡会提示当前启用的工具只是这个档位的一个子集。写操作默认逐次审批，保存后可以在 Agent 配置里为它单独开一份免卡白名单，与你手动对话时的审批设置互不影响。

## 联网档位

Web 能力卡有三档：关闭、域名门控（只有命中你建立的域名规则才免审批）、全开放（任意 URL 都免审批，包含把内容编码进 URL 外发的风险，谨慎开启）。

## 运行预算

每个 Agent 有两个预算维度：每日运行上限（次数）与单次运行时长。单次运行时长的默认值就是硬顶——三十分钟，只能往下调，不能调得更长。运行历史会显示每次的步数、token 用量与耗时；当天次数用满后本该触发但没跑的运行，会留一条「已跳过」的记录，不会无声消失。

## 在对话中 @ 委派

对话输入框里打 `@`，候选里的 Agent 组列出已启用的自定义 Agent。点名某个 Agent，相当于把任务直接交给它——它在自己的子会话里完成，完成后把结果带回当前对话。子任务运行较久时会先返回「运行中」，不阻塞当前对话，也可以随时停止。

只读型 Agent 被点名执行免额外确认；具备写入、联网或执行能力的 Agent 仍需要你确认后才动手。自定义 Agent 之间不能互相调用，不存在递归委派。

## 常见问题

- **改了触发器为什么没生效？** 检查这条触发器本身是否启用——新增的触发器默认关闭。
- **能不能让 Agent 完全不经确认地执行？** 可以为单个 Agent 单独配免卡白名单，但发送邮件、执行命令、安装技能、创建与修改自定义 Agent 这几类操作恒需确认，不能配成免卡。
- **导入的 Agent 一进来就能跑吗？** 不会，导入后默认停用，需要你先确认启用。
