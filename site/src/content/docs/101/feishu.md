如果你日常在飞书里办公，可以让 MailAgent 把**重要邮件**推到飞书：一张卡片告诉你来了什么信，卡片上的按钮还能直接触发 AI 起草回复。除此之外，服务出问题时也能往飞书发告警，让你第一时间知道同步是不是挂了。

## 你会收到什么

当一封邮件被 AI 判为 **紧急（Critical / Urgent）** 时，MailAgent 通过飞书应用机器人发来一张交互卡片，上面有：

- 邮件主题、发件人、AI 摘要、AI 优先级；
- 几个可点的按钮 ↓

| 按钮 | 作用 |
|---|---|
| **打开 Notion** | 跳到这封邮件的 Notion 页面 |
| **✨ 优化回复** | AI 检索上下文后，生成一份更高质量的回复发回给你确认 |
| **📝 创建草稿** | 基于已有的 AI 建议，直接在 Mail.app 里创建回复草稿 |

「📝 创建草稿」只在这封邮件**已经有 AI 建议回复**时才出现；点「✨ 优化回复」则会让 AI 重新检索同线程历史、生成更贴合上下文的版本，通常还会附一个"采纳并创建草稿"的后续按钮。

:::tip[草稿会自动同步到 Outlook]
通过飞书按钮创建的草稿落在你的 Exchange 账户里，会自动同步到 Outlook —— 你在手机、网页版 Outlook 上都能继续编辑和发送。
:::

## 怎么启用

```bash
# 在 .env 里打开通知开关
FEISHU_NOTIFY_ENABLED=true
```

还需要配置一组飞书相关的参数（应用机器人凭据等，以 `FEISHU_` 开头），具体字段见 `.env.example`。填好后重启后端：

```bash
pm2 restart mail-sync
```

:::note[默认是关的]
飞书通知默认关闭（`FEISHU_NOTIFY_ENABLED=false`）。只有显式打开并配好凭据后，重要邮件才会推送。
:::

## 服务告警（可选）

除了邮件卡片，MailAgent 还能在**服务异常**时往飞书发告警 —— 比如同步连续失败、邮件大量进入死信队列等。这由独立的告警开关控制：

```bash
ALERT_ENABLED=true
```

打开后，你不用盯着日志，也能在飞书里第一时间收到"同步可能出问题了"的提示。

## 卡片按钮背后发生了什么

点击卡片按钮后，飞书会把动作回调给 MailAgent 的处理服务（Openclaw），由它去操作 Mail.app / Notion 完成起草、更新状态等。整个过程对你透明，你只需在飞书里点按钮、看结果。

邮件在这一流程中的处理状态会这样流转：

```
未处理 → AI 已审阅 → 已同步 → 草稿已创建 → 已完成
```

## 常见疑问

- **开了开关但收不到推送？** 确认 `FEISHU_*` 凭据填全了、且重启过后端；再确认收到的邮件确实被判为紧急（普通邮件不推送）。
- **卡片上没有「创建草稿」按钮？** 这封邮件还没有 AI 建议回复，先点「优化回复」让 AI 生成一份。
- **想关掉？** 把 `FEISHU_NOTIFY_ENABLED` 改回 `false` 重启即可。

> 深入了解：卡片按钮回调的完整契约见 `docs/reference/integrations/openclaw-callback-guide.md`。
