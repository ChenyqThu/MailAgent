## 一句话

**MailAgent 是一个以邮件为起点的本地优先个人 AI 工作台。** 邮件落地即被读完、分类、写摘要、起草回复；事项、日历、联系人、资料是你工作的对象；一组有名字、有边界的 Agent 处理日常，你只过问例外与关键决定；每一步都能点回原文核对。

它运行在你自己的电脑上，邮件正文、附件与索引都存在本机的数据库里——这就是「本地优先」：数据先属于你的机器，Notion 只是一份可选的镜像。

## 能力地图

MailAgent 是一体化的桌面 App，内置完整的同步与 AI 服务——装好即可用，不必单独安装 Python 或命令行。下面每一项都开箱可用或一步开启。

| 域 | 一句话 | 深入了解 |
|---|---|---|
| **今日** | 当天需要你过问的事收在一页：待批的审批、今天的会、待回邮件、临期事项、Agent 刚交出的成果。 | [今日](/101/today/) |
| **邮件** | 入库即处理：分类、优先级、摘要、动作建议写进邮件本身；正文与附件全部进入全文索引。 | [日常工作流：收件箱](/101/daily-inbox/) · [撰写与回复](/101/compose-reply/) · [搜索](/101/search/) |
| **日历** | 邮箱日程、事项截止、Agent 排程聚合在一张表上，支持拖拽改期。 | [日历](/101/calendar/) |
| **事项** | 把一件要推进的事变成对象：背景与目标、行动项、干系人、关联资料、进展时间线；跟进 Agent 只提案，你逐条采纳。 | [事项](/101/matters/) |
| **通讯录** | 从往来邮件与会议自动建档，按邮箱归并成人；AI 画像句句带引证。 | [通讯录](/101/contacts/) |
| **资料库**（macOS） | 挂载本机目录、汇总邮件与对话附件成一棵文件树；文件留在原处，写入范围由服务端强制。 | [资料库](/101/library/) |
| **AI 对话** | 随时唤起主 Agent，`@` 邮件、事项、资料或其他 Agent；多家服务商、上百个模型自由选择。 | [AI Chat 面板](/101/ai-chat/) · [模型与服务商](/101/models/) |
| **团队与自定义 Agent** | 主 Agent 有名字与头像；自定义 Agent 按定时、邮件、日程、会前等触发器工作，每次执行留下完整记录。 | [团队与自定义 Agent](/101/team-agents/) |
| **群聊**（Labs） | 几位 Agent 在同一个群里接力，也可以开子话题。 | [群聊](/101/group-chat/) |
| **报告** | 日报、周报、月报，统计由代码计算，每条数字与引用可点回原文。 | [报告](/101/reports/) |
| **通知中心** | 持久化的通知面板：审批待办、Agent 结果、系统告警集中在一处。 | [通知中心](/101/notifications/) |
| **外部连接**（MCP） | 把 Notion、Jira、GitHub 等外部服务接进对话，或把收件箱能力交给你自己的 Agent。 | [外部连接](/101/connectors/) |
| **飞书对话** | 在飞书私聊里和主 Agent 对话，按钮直接完成审批。 | [飞书对话](/101/feishu/) |

> 大多数能力默认可用或一步开启；模型服务、Notion、飞书等需要你自己的密钥或授权才会启用。

## 三件让它不一样的事

**1. 入库即处理，不是事后批量。** 分类、优先级、摘要、动作建议在邮件刚到的那一刻就写好；今日页把当天要你拍板的事收在一起，不用自己再扫一遍收件箱。

**2. AI 写文案，代码守数字。** 报告和画像里的统计数字、链接、邮件 ID 由代码确定性生成，AI 只负责措辞与组织；出错的至多是用词，不会是事实，且每一条都能点回原邮件核对。

**3. 本地优先，写入有边界。** 邮件、索引与文件都存在你自己的电脑上；每个工具都有审批档位，发送邮件、执行命令、改动 Agent 配置默认需要你确认；Agent 能写到哪里由服务端判定，不由它自己决定。

## 系统要求

| 项 | 要求 |
|---|---|
| macOS | 12（Monterey）及以上，**Apple 芯片**（M 系列）。 |
| Windows | Windows 10 / 11，x64。 |
| 邮箱 | 企业 Exchange / Microsoft 365（DavMail 桥接），或 Windows 上已登录的经典版 Outlook；macOS 也可以用本机 Mail.app 账户。 |
| 模型服务 | 自带一个模型服务商的 API Key（内置多家官方模板任选其一），或自建 OpenAI / Anthropic 兼容中转。 |
| Notion（可选） | 不填也能用：同步、搜索、AI 分类、事项、通讯录、资料库全部在本地运行。想额外镜像一份到 Notion，一键授权即可。 |

:::caution[两种邮箱接入路径]
DavMail 目前经 Exchange Web Services（EWS）访问 Exchange Online。微软计划自 **2026-10-01 起默认阻断 EWS**，**2027-04-01 完全退役**。迁移进展见 [用 DavMail 接入企业邮箱](/101/davmail-setup/)。Windows 上的本机 Outlook 后端与 macOS 的 Mail.app 路径不受这两个日期影响。
:::
