## 一句话

**MailAgent 在邮件落地的那一刻就替你读完它。** 它自动给每封邮件分类、定优先级、写一句话摘要、起草回复——重要的浮上来，杂讯沉下去，而且每一条结论都能点回原邮件核对。

它运行在你自己的 Mac 上，邮件数据存在本机，是一个"本地优先"的工具，不是又一个把你的邮箱搬上别人服务器的云服务。

:::tip[读这一页就够了吗？]
不够，但这是起点。读完本页你会知道 MailAgent 能替你做什么、需要准备什么。接着按左侧目录从 **[安装桌面 App](/101/install-app/)** 一步步走——下载、连邮箱、让 AI 接管，几分钟就能跑到第一封被 AI 处理的邮件。
:::

## 它替你做什么

MailAgent 就是一个桌面 App——它**内嵌了在后台同步、分类邮件的完整后端**（自带运行环境，无需另装 Python 或命令行工具），你日常点开来看邮件、聊天、回信。下面这些能力开箱即得。

| 能力 | 它意味着什么 | 默认 |
|---|---|---|
| **邮件实时同步** | 收发邮件、附件、同一话题的来回（线程）自动镜像到 Notion 数据库，作为可检索的归档。 | 常驻 |
| **AI 自动分类** | 每封邮件入库即被打上类别、优先级（紧急/重要/一般/低）、一句话摘要和动作建议，写进邮件本身。 | 可选 |
| **全文搜索** | 正文 + 附件文本（PDF / Word / PPT / Excel）一起进入全文索引，中文也能搜，命中处高亮。 | 随同步开启 |
| **AI Chat 面板** | 在桌面 App 里就当前邮件向 AI 提问、让它跨邮件检索、流式起草回复。 | App 内 |
| **一键翻译** | 英文邮件一键翻成中文，详情页、工具栏、批量都能用。 | App 内 |
| **会议邀请识别** | 邮件里夹带的会议邀请（.ics）自动解析成日历事件。 | 常驻 |
| **日历同步** | 把 Exchange 日历增量同步到本机，配合邮件里的会议邀请统一查看。 | 关（可开） |
| **灵动岛通知**（需另装插件） | 重要邮件以灵动岛卡片弹出，可一键已读 / 标旗 / 起草。 | 关 |
| **飞书通知** | 紧急 / 重要邮件推到飞书，带交互回复按钮。 | 关 |
| **远程 Web 访问** | 出差时用 iPad / iPhone / 别人的电脑通过浏览器查看邮件。 | 关 |
| **日 / 周 / 月报** | AI 每天回顾过去 24 小时邮件，策展成一份读得完的结构化报告。 | 关 |

> 上表里标"关 / 可选"的能力默认不开，按你的需要逐个启用即可——刚上手时，只用前几行就已经很顺手。

## 三件让它不一样的事

**1. 入库即处理，不是事后批量。** 分类、优先级、摘要、动作建议在邮件刚到的那一刻就写好。打开列表，一眼就知道哪封该先看，不用自己再扫一遍。

**2. AI 写文案，代码守数字。** 一个邮件助手最怕"编"。MailAgent 的纪律是：统计数字、链接、邮件 ID 全部由代码确定性回填，AI 只负责措辞和分组。万一 AI 说错，错的也只是用词，不会是事实。报告里每个数字、每个引用都能点回真实邮件核对。

**3. 本地优先，账目透明。** 邮件数据存在你的 Mac 上。每一次 AI 调用都记账——处理量、消耗、耗时、缓存命中、同步是否健康，都摊在看板上，不是装饰图表。

## 系统要求

在安装之前，先确认你的环境满足这些条件。

| 项 | 要求 |
|---|---|
| 操作系统 | macOS 12（Monterey）及以上；Apple Silicon（M 系列）或 Intel x64 均可。 |
| 邮箱 | 一个企业 Exchange / Microsoft 365 邮箱（通过 DavMail 桥接），或已在 macOS 自带 **Mail.app** 里添加好的账户（AppleScript 路径）。 |
| Notion（可选） | 默认不需要——邮件正文与附件都存在你 Mac 本地的 SQLite，App 直接读写。只有想把邮件归档**额外镜像一份到 Notion** 时才需要一个 Notion 工作区（建库步骤见 [（开发者）从源码运行后端](/101/install-backend/) 里的"可选：建 Notion 镜像库"）。 |
| 运行环境 | 无需自己装 Python——桌面 App 已内置可独立运行的运行环境。（仅从源码跑后端的开发者才需要 Python 3.11+。） |
| 网络 | 首次启动需联网验证 Notion API，以及（如启用 AI）验证 LLM 网关。 |
| AI（可选） | 一个 Anthropic 兼容的 LLM 网关 Key，或一个 Notion Custom Agent。不填也能用同步与搜索，只是没有 AI 分类与 Chat。 |

:::caution[关于邮箱后端]
MailAgent 支持两条邮箱接入路径：**DavMail**（桥接企业 Exchange，速度快，是当前推荐主路径）和 **AppleScript**（直接驱动 macOS Mail.app，作为始终可用的兜底）。两者一行配置即可切换。需要注意：DavMail 当前依赖的 EWS 协议将于 **2026-10-01 被微软关停**，迁移方案见后续章节与[迁移路线图](https://github.com/ChenyqThu/MailAgent/blob/main/docs/reference/architecture/roadmap-post-cutover.md)。AppleScript 路径不受影响。
:::

## 几个你会反复看到的词

刚上手时，下面这些词会在界面、日志和文档里反复出现，先有个印象即可，不必现在记住。

- **后端 / mail-sync**：在后台跑的同步主服务，负责把邮件搬进本地数据库再镜像到 Notion。
- **桌面 App**：你日常打开的图形界面，读邮件、搜索、聊天、回信都在这里。
- **SQLite**：存在你 Mac 上的本地数据库文件（`data/sync_store.db`），是邮件正文和附件的"权威副本"，Notion 是它的镜像。
- **DavMail**：把企业 Exchange 邮箱翻译成标准协议的桥接程序，让 MailAgent 能高速读写邮件。
- **Notion Integration / Token**：你在 Notion 里创建的"机器人"，MailAgent 用它的 Token 往你的数据库里写邮件。

更完整的术语表见 [故障排查 FAQ](/101/troubleshooting/)。
