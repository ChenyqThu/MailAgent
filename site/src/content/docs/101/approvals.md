MailAgent 让 AI 替你做事，但每一件「动手」的事都先经过一道判定：这个工具可以直接执行，还是要先问你一声。这道判定按工具逐个设置，而不是一个全有或全无的总开关。

## 逐工具三档

设置 → AI →「工具审批档」把每个工具分成三档：

- **直接执行**——AI 调用时不弹卡，直接做。
- **先确认**——每次调用前弹出审批卡，等你批准。
- **禁用**——这个工具对 AI 不可见，模型根本不知道它存在。

工具按用途分了十二组：邮件操作、草稿、联网、日历、事项、通讯录、身份与技能、Skill 供应链、Agent 配置、本地文件与命令、外发与外呼、资料库。每组都能批量设置——全部直接执行、全部先确认、全部禁用，或者全部回到默认档；也可以点「全部重置」，一次清空所有你手动改过的覆盖，回到出厂默认。

出厂默认已经按风险分了档：草稿撰写与更新、标记、归档、置顶、重新同步这类高频且可逆的操作默认直接执行；日历改期、回复邀请、删除，以及修改 Agent 配置这类默认仍需确认，但你可以自行调成直接执行。想要快速放开一批常用的可逆操作，可以用「编辑放行预设」——一键把草稿、联网、文件读写等十几个工具设为直接执行。

:::note[只管你亲自在场的对话]
工具审批档只作用于你在应用里和助手对话的场景。后台定时运行的自定义 Agent 用的是各自单独配置的白名单规则；飞书对话用的是固定的裁剪规则（读免审批，写恒需确认）。改这里的档位，不会影响那两处。
:::

## 恒需确认、不可调低的操作

有几类操作无论怎么设置都会弹卡，不能改成直接执行：

- **发送邮件**——唯一的免卡形状是你自己设定的收件人白名单：收件人（含抄送、密送）全部命中白名单才会跳过确认，只要有一个没命中，就恒需确认。白名单为空时，发送永远需要确认。
- **执行本机命令**——只有命中你在自定义 Agent 里配置的自动化策略白名单才会免卡，其余一律弹卡。
- **安装技能**——供应链的每一步（下载、解包、校验）都需要你确认，草稿区里的脚本在任何情况下都不会被执行。
- **创建与修改自定义 Agent**——包括通过对话让助手帮你建/改 Agent，审批卡会展示改动前后的对比。

## 全局授权模式

对话框左下角可以切换整体的授权强度：

- **手动授权**（默认）——按上面逐工具设置的档位决定弹不弹卡。
- **完全授权**——所有操作直接执行，不再询问，包括真实发信、本机命令执行、Skill 安装与日历改动。切到这一档需要额外确认一次，且对之后所有会话都生效，需要谨慎选择。

## 审批卡上看到什么、怎么回应

弹出的审批卡会显示这次要做什么——如果是回复邮件，收件人和内容由服务端按真实载荷生成，不是转述模型自己的说法。你可以：

- **批准**——按卡片上的内容执行。
- **编辑参数**——只有卡片标出的字段可以改，其余参数由服务端锁定；改完点批准，执行的是改后的版本。
- **拒绝**——可以附一句拒绝理由，说明为什么不批准、希望改成什么做法，这句话会回传给 AI，它知道自己哪里想错了。

批准框上还有一个「记住：以后不再询问这类操作」的选项，勾上之后，这个工具会被设为直接执行，此后在与助手的对话里不再弹卡；后台自动运行的 Agent 不受影响，需要改回的话去设置里调整。

## 审批的有效期

审批卡不会一直等你。外发类操作（比如发送邮件）过期时间是 2 小时，其余操作是 24 小时。超过这个时间没有处理，审批会明确显示已过期，不会在你事后随手点一下时悄悄执行。

## 审批会出现在哪里

- **对话内**——最常见的位置，切换会话、关闭面板都不会丢失待批的审批卡，回来仍然可以处理。
- **今日**——「等你拍板」一节汇总当天所有待处理的审批，回应方式有三种：直接执行、改了参数再执行，或者写一句回复。
- **通知中心**——铃铛图标下的通知面板会收录待处理的审批。
- **飞书**——需要审批的操作会以按钮卡片的形式发到你的飞书私聊，点一下就能放行，不用打开应用。
