资料库把邮件附件、对话里产生的文件、Agent 写下的文档，以及你自己挂载进来的本机文件夹，汇成一棵文件树，配一个可以搜索的索引。文件本身留在磁盘原来的位置，资料库只是给它们建了一份目录。

想让 Agent 参考一份合同、一份规格文档，或者想把某次对话产出的文件长期留存时，都可以用它。

:::note[仅 macOS 桌面客户端提供]
资料库依赖本机服务，Windows 版和远程网页版目前都不显示这个页面。
:::

## 第一次使用

左侧导航「资料库」下有六个根：

| 根 | 说明 |
|---|---|
| **邮件附件** | 只读投影，不占用额外磁盘空间；随邮件删除消失，长期保留要点「另存到资料库」 |
| **对话附件** | 对话里发送或生成的文件，发送即入库 |
| **Agents 文档** | Agent 可以读写的地方 |
| **我的文档** | 你自己的文件；只有主 Agent 在你允许时可以写 |
| **挂载的文件夹** | 你自己挂进来的本机目录 |
| **废纸篓** | 软删的文件，保留 30 天 |

要把电脑上已有的目录接进来，用「添加文件夹」挂载：选一个目录，文件留在原处不搬动，只建索引；可以设为只读或可写，卸载时磁盘上的文件一个都不动，重新挂回同一个目录会沿用之前的文件记录。单个目录最多 20,000 个文件，会自动跳过 `.git`、`node_modules` 和隐藏目录。

## 日常操作

- **预览**：Markdown、网页、图片可以直接在应用内看；PDF、Office 文档、CSV 看到的是抽取出的正文，要看原始排版用系统里对应的应用打开。HTML 文件按浏览器网页处理——脚本和样式正常渲染，但与应用本身隔离。
- **历史版本**：文本文件每次写入都会留一份快照（每个文件最多 50 条），可以查看历史并回滚到任意一版；如果文件在应用之外被改过，回滚前会先提示冲突。
- **删除与恢复**：库内文件（邮件附件投影区之外的那些）删除后进资料库自己的废纸篓，保留 30 天，随时可以恢复;挂载目录里的文件删除走的是系统废纸篓，在访达里恢复。
- **搜索**：入口有三处——⌘K 命令面板的「资料库」组、`/search` 页的资料库结果组、资料库页内的全库搜索。默认按关键词匹配；在设置里下载语义模型（约 614 MB，只需一次）之后，搜索会同时用关键词和语义两条路径给出结果。除了这一次下载，语义检索全程在本机运行，不会再联网。

## 让 Agent 参与

Agent 有 7 个文件工具——列目录、读取、搜索、追加、写入、移动、删除，对应设置里的「资料库」能力卡（关闭 / 只读 / 可写三档）。

写入范围由服务端强制，不是靠提示词约束：

- 自定义 Agent 只能写「Agents 文档」；
- 主 Agent 另外还能写「我的文档」；
- 邮件附件投影区和废纸篓一律拒绝写入；
- 挂载的文件夹要单独设为「可写」才能被 Agent 改动；
- Agent 写入的文件类型限定在 `.md`、`.markdown`、`.html`、`.txt`、`.csv`、`.json`。

**无人值守运行**（比如定时触发的自定义 Agent、事项跟进）只放行「追加」这一个动作，而且仍然限定在「Agents 文档」下——整体覆写、移动、删除都需要你在对话里审批。

对话里发送的附件、以及 AI 生成的图片，会自动归入「对话附件」；邮件附件行有「另存到资料库」；事项可以关联资料库里的文件；写信时也可以从资料库直接选一个文件作为附件。

## 限制与常见问题

- **仅 macOS 桌面客户端**：Windows 与远程网页版目前都看不到这个功能。
- **不做 Notion 同步**：资料库是完全独立的本机索引，不会镜像到 Notion。
- **不支持在应用内直接编辑 Office 文档**：Office、PDF 这类文件只能预览抽取出的正文，编辑要用系统里对应的应用打开。
- **树内暂不支持拖拽移动**：需要移动文件用右键菜单里的「移到…」。
- 语义模型下载是一次性的；如果没下载，搜索会自动退化为纯关键词匹配，功能不受影响。
