AI Chat 是桌面 App 的招牌功能：一个常驻右侧的对话面板，让你**就当前这封邮件**跟 AI 聊——问它"这封在说什么""该怎么回""帮我查一下上次的报价"，它能读邮件、跨邮件检索、流式起草回复。

## 打开面板

在邮件详情界面打开右侧的 AI Chat 面板（约 360px 宽）。它带着当前选中邮件的上下文，所以你可以直接问"这封邮件要我做什么"而不用复制粘贴。

## 选后端

面板顶部可以选用哪个 AI 后端，对应你在[首次配置](/101/onboarding/)里填的两种：

- **Notion Agent（如 Jarvis）**：基于你的 Notion Custom Agent。适合已有 Notion Agent 的用户，但**不支持工具调用**，会以单轮问答方式工作。
- **Custom API**：自托管的 OpenAI / Anthropic 兼容网关。**支持完整的工具调用**——跨邮件检索、流式起草都在这条路径上。

:::note[想要完整能力就用 Custom API]
下面讲的"工具调用行""跨邮件检索""流式起草卡"都依赖工具调用协议，只在 Custom API 后端下可用。选 Notion Agent 时面板会自动退回到更简单的单轮对话。
:::

## 对话里你会看到什么

当 AI 需要查资料或动手时，面板里会实时显示它的动作，而不是只给你一段最终文字：

- **工具调用行**：AI 决定去搜邮件、读正文、列附件时，会出现一行说明它在做什么（比如"正在全文检索…"）。你能看见它"思考"的步骤。
- **流式起草卡**：让 AI 起草回复时，草稿会**一边生成一边显示**在一张卡片里，带闪烁的光标，写完你可以直接采用或继续让它改。

AI 能调用的工具覆盖常见诉求：搜邮件、读某封正文、列线程、跨邮件全文检索、看附件、看 AI 字段，以及（经你确认后的）标旗、归档、起草回复。

## 跨邮件检索

你不必把面板局限在当前这封。可以让 AI"找一下我和这个客户过去关于报价的所有邮件"——它会用全文检索跨邮件查找，把相关线索拉进对话。这让 AI Chat 不只是"读这一封"，而是能帮你在整个邮箱里串起一件事。

## 切换模型

Custom API 后端支持切换具体模型（取决于你的网关提供哪些）。同一个对话里也可以根据任务难度换模型——简单问题用快的，复杂梳理用强的。

## 写操作要你点头

涉及"动手"的操作（标旗、归档、发起草稿）**不会静默执行**。AI 提议时会弹出一个确认弹窗：

- **预览模式**：以只读 JSON 给你看它打算做什么。
- **编辑模式**：你可以在一个文本框里改它的参数，改完的值会生效，AI 下一轮也能看到你的修改。

确认后才执行。所以你始终是最后拍板的人，不用担心 AI 擅自发信。

## 历史会持久化

每封邮件的对话历史会被保存下来。下次再点开同一封邮件，之前聊到哪儿还在。换一封邮件就是另一段独立的对话，互不串台。

:::tip[每次调用都有账]
AI Chat 的每一次工具调用都会被记录（状态、耗时、你是否编辑过参数）。配合 [报告与看板](/101/reports/)，你能看到 AI 到底替你跑了多少、花了多少——透明可查，不是黑盒。
:::
