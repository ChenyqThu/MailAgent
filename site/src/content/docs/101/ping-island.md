灵动岛通知把"有重要邮件来了"这件事，从一个容易错过的角标，变成屏幕顶部刘海处的一次轻量提醒。你不用切到 MailAgent，就能在岛上看到这封邮件是谁发的、有多急，并直接做出动作。

## 它长什么样、能做什么

当一封重要邮件到达（或 AI 判定为紧急）时，灵动岛会浮现一条提醒，展示：

- **发件人** 和 **主题**；
- **优先级**（紧急 / 重要 / 普通…）；
- **AI 建议的动作**（如"需要回复"）。

对于紧急邮件，岛上还会给出一组一键动作按钮：

| 按钮 | 作用 |
|---|---|
| 打开 Mail.app | 在邮件客户端里直接打开这封信 |
| 去 Notion 处理 | 跳到这封邮件的 Notion 页面 |
| 创建回复草稿 | 让 AI 起草一份回复（走 Mail.app 草稿） |
| 稍后再看（1 小时） | 暂时收起，1 小时后再提醒 |
| 标记完成 | 标记这封邮件已处理，清掉提醒 |

:::note[把 mascot 拖出来当常驻浮窗]
如果你的 ping-island 支持"离岛模式"，可以把邮件 mascot 从刘海里拖出来，固定在屏幕右上角，实时显示**当天未读邮件数**；点一下就回到 MailAgent 收件箱。
:::

## 怎么启用

灵动岛是一个**独立的小 App**（ping-island），MailAgent 通过它来显示通知。启用分两步：

### 1. 安装 ping-island

从 ping-island 的发布页下载并安装它的 macOS App，启动它（确保它在运行）。

### 2. 在 MailAgent 里打开开关

```bash
# 在 .env 里加这一行，然后重启后端
PING_ISLAND_ENABLED=true
```

```bash
pm2 restart mail-sync
```

启用后，重要邮件、AI 处理完成、同步失败等事件就会自动推送到灵动岛。

:::tip[语言跟随]
岛上的文字（"新邮件 / 张三"等）支持中英文，跟随你的语言设置。不用单独配置。
:::

## 安全与隐私

- 灵动岛和 MailAgent 在**同一台 Mac 上**通过本地通道通信，通知内容不出本机，无需任何账号或密钥。
- 这是一个**容错（fail-open）**的功能：如果 ping-island 没装、没开、或临时连不上，MailAgent 的邮件同步**完全不受影响**，只是当时不显示岛上通知而已。Mac 睡眠/重启后通道会自动恢复并补发积压的提醒。

## 常见疑问

- **装了也开了，但岛上没反应？** 先确认 ping-island App 正在运行；再确认收到的邮件确实被判为重要/紧急（普通邮件默认只留一个 dock 角标，不主动展开刘海）。
- **想关掉？** 把 `PING_ISLAND_ENABLED` 改回 `false` 重启即可，或直接退出 ping-island App。
- **它会替代 MailAgent 主界面吗？** 不会。灵动岛是**通知层**，负责"提醒 + 一键动作"；MailAgent 桌面 App 是**浏览层**，负责看全部邮件。两者互补。
