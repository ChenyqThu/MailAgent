这是你每天打交道最多的界面。本节带你把收件箱用顺。

## 三栏布局

桌面 App 主界面分三栏，从左到右：

1. **左栏 — 文件夹与 AI Agents**：收件箱、发件箱、存档、已标旗等邮箱，下方是你配置的 AI Agents（如 Notion Agent / Jarvis）。每个邮箱右侧显示未读数。
2. **中栏 — 邮件列表**：当前邮箱的邮件。每一行显示发件人、主题、时间，以及 AI 打的优先级标记——**列表本身就告诉你哪封该先看**。
3. **右栏 — 详情 + AI 面板**：选中邮件的正文、附件，以及顶部的 AI 字段块（优先级、动作、类别、摘要）。

## 快捷键

熟练之后，手不用离开键盘。核心快捷键：

| 快捷键 | 作用 |
|---|---|
| `?` | 打开快捷键帮助弹窗（最全的一张表在这里） |
| `⌘K` | 命令面板——切邮箱 / 搜邮件 / 跳路由 |
| `⌘,` | 打开设置 |
| `J` / `K` | 上一封 / 下一封 |
| `R` | 对当前邮件 AI 起草回复 |
| `T` | 翻译当前邮件 |

:::tip
快捷键的"权威清单"始终在 `?` 弹窗里——它会列出所有已接通的绑定，还没接通的会标个 "soon"。记不住就按 `?`。
:::

## AI 字段块：一眼看懂一封邮件

选中一封邮件，右栏顶部会显示 AI 在它入库时就写好的结构化信息：

- **优先级（Priority）**：紧急 / 重要 / 一般 / 低，列表里也会以颜色标记。
- **动作建议（Action）**：比如"需要回复""仅供参考"。
- **类别（Category）**：邮件归类。
- **一句话摘要（Summary）**：不用读完正文就知道讲了啥。

这些不是事后批量算的，而是邮件刚到时就处理好的，所以你打开列表的那一刻它们已经在那儿了。

:::note[AI 字段从哪来]
这些字段由 AI 分类生成（本地 LLM 或 Notion Agent，取决于你在[首次配置](/101/onboarding/)里选的后端）。如果你没启用 AI，这些字段会是空的，但同步、搜索、阅读照常工作。
:::

## 阅读正文：安全的沙箱渲染

邮件正文在一个**沙箱化的 iframe** 里渲染。这意味着邮件里的脚本、追踪像素等不会影响 App 本身，正文里的链接点击会安全地在外部浏览器打开。HTML 邮件的排版、内联图片都会忠实呈现。

附件列在正文下方，可以预览或下载。Office 附件（docx / pptx / xlsx）后端还会自动转换出 PDF / CSV 衍生件，方便快速查看。

## 一键英译中

读到英文邮件，按 `T`（或点详情页 / 工具栏的翻译按钮），正文会被翻成中文。批量场景下，也可以多选邮件后一起翻译（见下文批量动作条）。

翻译用的是你在密钥设置里填的 **LLM API Key**。如果翻译没反应，多半是 Key 没填或网关测试没通过——回 [应用内首次配置](/101/onboarding/) 检查。

## 标旗、已读，双向同步

在列表或详情里标旗（flag）、标已读 / 未读，这些状态会**双向同步**：你在 App 里改，会反映到 Mail.app 和 Notion；反过来在 Notion 或 Mail.app 里改，也会同步回来。底层走的是一个统一的异步派发机制（outbox），所以偶尔会有亚秒级延迟，属正常。

## 批量动作条：一次处理一批

在列表里多选邮件（按住选、或用快捷键圈选），底部会浮出**批量动作条**，可以对选中的一批邮件一次性执行：

- **批量 AI 分类**：对还没分类的邮件统一跑 AI 分类。
- **批量起草回复**：让 AI 给一批邮件分别起草回复。
- **批量翻译**：把选中的英文邮件统一翻成中文。
- **批量重传 Notion**：把选中的邮件重新同步到 Notion（适合修过 schema 后补传）。

批量操作适合"周一早上清积压"这种场景：选一片、一键处理，省得一封封点。
