邮件是你每天打交道最多的对象。这一节讲清楚 v3 的工作区怎么用，以及处理邮件的常用操作。

## 工作区形态

桌面 App 左侧是一条常驻的**图标导轨**（56px），点它切换到日历、事项、通讯录等其他域；紧邻导轨的是当前域的**二级栏**。邮件域的二级栏顶部是「写邮件」按钮，下面分两段：常用邮箱视图（收件箱、发件箱、已标旗、存档、所有邮件）与你勾选同步的自定义文件夹树。

- `[` 收起或展开当前域的二级栏，`]` 展开并把焦点移到二级栏第一项——键盘操作全程不用碰鼠标。
- 悬停在导轨的其他域图标上，会临时露出那个域的二级栏内容，不用真的切过去看一眼。

## 多标签

同一窗口可以同时打开多份内容：

| 操作 | 快捷键 |
|---|---|
| 开新标签页 | `⌘T` |
| 关闭当前标签 | `⌘W` |
| 重新打开刚关闭的标签 | `⇧⌘T` |
| 循环切换标签 | `⌃⇥` / `⌃⇧⇥` |
| 跳到第 1-9 个标签 | `⌘1`-`⌘9` |

默认情况下，单击一封邮件会**复用同一个浏览标签**，不会越点越多；想让某个标签留住，右键选「在新标签页打开」，或点标签上的图钉「保留标签」——保留后的标签不会被下一次点击替换，已经打开过的邮件也不会重复开出第二个标签。正在编辑回复、有未保存内容的标签同样不会被替换。如果想让每次点击都新开一个标签，可以在设置里打开「每封邮件在新标签页打开」（默认关闭）。

## 文件夹下拉与计数

列表头部的文件夹下拉可以快速切换当前查看的邮箱，旁边带着未读或总数的计数徽标：收件箱看未读、草稿箱看总数、已标旗看总数、所有邮件看未读，自定义文件夹也各自显示未读数。常用的文件夹可以「固定到列表头」，直接在顶部露出，不必每次都点下拉菜单（固定数量有上限）。

## 自定义文件夹

MailAgent 默认同步收件箱与发件箱；如果你在 Outlook 里还有其他文件夹想一并处理，去**设置 → 自定义文件夹同步**勾选它们（仅 DavMail 后端可用）。勾选后的文件夹享受和内建邮箱一样的能力：AI 分类、Notion 同步、全文搜索。

每个已同步的文件夹可以单独配置：

- **图标**：24 个动效图标可选，侧边栏按你选的图标渲染，收起时仅显示图标。
- **通知**：默认关闭——新加入的文件夹缺省不推送通知，需要的自己打开（白名单机制）。
- **AI 分类**：默认开启——新加入的文件夹缺省会跑 AI 分类，不想要的自己关掉（黑名单机制）。
- **顺序**：拖拽调整，侧边栏按这个顺序显示。

两个开关和排序改完立即生效，不需要重启同步服务。内建邮箱（收件箱、发件箱等）不受这两个开关约束，图标也固定不可换。

## 线程折叠

同一条线程在列表里默认折叠成一行，代表整条线程：线程内任意一封带旗标或被置顶，折叠行就显示对应标记；点击折叠行会级联展开整条线程的所有成员。收起动作有平滑过渡，下方行会顺势上移补位，不是生硬的跳动（开启「减弱动态效果」时退回瞬时收起）。详情页里更早的往来邮件同样会折叠成「对话中早期邮件」，可以「全部展开」或「全部收起」查看。

## 筛选、排序与快捷键

列表头部的筛选菜单支持组合条件：优先级、类别、已标记、已完成、收件人是我、有附件；排序支持按日期、发件人、主题或重要性，并可选正序或倒序。

常用快捷键：

| 快捷键 | 作用 |
|---|---|
| `⌘K` | 命令面板——切邮箱、搜邮件、跳路由 |
| `⌘,` | 打开设置 |
| `?` | 打开快捷键帮助（最全的一份清单在这里） |
| `J` / `K` | 下一封 / 上一封 |
| `S` | 标旗三态循环（未标旗 → 已标旗 → 已完成 → 未标旗），与点击旗标按钮一致 |
| `U` | 切换已读 / 未读 |
| `E` | 归档（等同标旗三态里的「已完成」终态） |
| `⌥T` | 翻译当前邮件 |
| `⇧⌘O` | 只看未读 |
| `⌥⌘O` | 只看已标旗 |
| `⇧⌘A` | 只看有附件 |

## AI 字段面板：一眼看懂一封邮件

选中一封邮件，右栏顶部显示 AI 在它入库时就写好的结构化信息：

- **优先级**：紧急 / 紧迫 / 重要 / 一般 / 低，列表里也用颜色标记。
- **动作建议**：比如「需要回复」「仅供参考」。
- **类别**：邮件归类，你可以自定义分类法。
- **一句话摘要**：不用读完正文就知道讲了什么。

这些字段不是事后批量算的，邮件刚到时就处理好了，打开列表的那一刻它们已经在那儿。

:::note[AI 字段从哪来]
这些字段由 AI 分类生成，具体走本地 LLM 还是 Notion Agent，取决于你在[首次配置](/101/onboarding/)里选的后端。没启用 AI 时这些字段是空的，但同步、搜索、阅读照常工作。
:::

## 一键翻译

读到外文邮件，按 `⌥T`，正文会被翻译成中文；再按一次可以切回原文，或重新翻译。翻译用的是你在密钥设置里填的模型 API Key，没反应多半是 Key 没填或网关测试没通过，回[首次配置](/101/onboarding/)检查。

## 远程图片默认拦截

出于隐私考虑，邮件正文里的远程图片默认不会自动加载：会看到一条提示「为保护隐私，已拦截 N 张远程图片」，点击放行后再经过签名代理加载，不会让你的设备直接连去发件方指定的图片服务器。
