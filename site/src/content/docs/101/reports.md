报告 Agent 帮你把"昨天到底来了哪些邮件、哪些已经处理了、哪些还得你亲自看"这件事，浓缩成一份**结构清晰、可点击溯源**的内容。它每天（或每周、每月）自动生成，你在 MailAgent 里直接读，不用自己翻收件箱回顾。

## 报告里有什么

一份日报通常按四块来组织：

1. **总览**：一段话概括这段时间的邮件全貌；
2. **统计卡**：总数 / 未读 / 紧急 / AI 已处理 / 待处理等数字；
3. **分组明细**：
   - 「需要你关注」—— 还得你亲自处理的；
   - 「AI 已处理」—— Jarvis 已经帮你分类/起草的；
   - 「FYI / 一般」—— 知道一下即可的；
4. **关键信息**：你必须知道的要点 + 高亮提示。

每一封邮件都是一行可点击的条目：点它**直接打开这封邮件**，也能跳到对应的 Notion 页面。

:::tip[数字不会被 AI 编造]
里面的统计数字、链接、邮件归属都是**由程序按真实数据算出来再填进去的**，AI 只负责写文字（总览、点评、分组）。所以你看到的"紧急 5 封"一定对得上真实邮箱，不会出现幻觉数字。
:::

## 日 / 周 / 月报的区别

| 周期 | 覆盖窗口 | 侧重 |
|---|---|---|
| **日报** | 过去 24 小时 | 逐封策展明细（关注 / 已处理 / FYI） |
| **周报** | 过去 7 天 | 趋势 + 跨项目进展（精选邮件） |
| **月报** | 过去 30 天 | 高层回顾 + 趋势图 |

周报和月报会用简单的趋势图展示变化，帮你看清"这周比上周忙了多少"这类问题。

## 怎么启用

报告 Agent 默认关闭，分两层开关：

```bash
# 1. 总开关（在 .env 里）
MAILAGENT_REPORT_AGENT_ENABLED=true
```

```bash
pm2 restart mail-sync
```

第 2 层：在应用内「Agents」页里，给某个具体 agent（日报 / 周报 / 月报）单独打开。

:::note[两层开关都要开]
总开关 `MAILAGENT_REPORT_AGENT_ENABLED` 打开后，每个具体 agent 还需要在应用里**单独启用**。种子里的日报默认是关的，所以即便开了总开关，也要进 Agents 页把它打开才会生成。
:::

## 在哪看、怎么管

在 MailAgent 侧边栏的 **AI AGENTS** 区，点进 **Agents 页**，这里有三个标签：

- **Agents**：每个 agent 一张卡片，可以开关、看下次运行时间、点 **Run now** 立刻生成一份、进配置面板；
- **报告**：所有已生成内容的列表（按日期、周期筛选，带状态标记），点开就是完整内容；
- **Chats**：你的 AI 对话历史。

在某个 agent 的配置面板里，你可以：

- 启用 / 停用；
- 改它的提示词（prompt）—— 决定措辞和侧重；
- 改排程和时间窗口（比如日报几点生成）；
- 选用的模型；
- **Run now** 立即跑一份，不用等到下个排程点。

## 和 KOS 知识大脑的关系

如果你开启了知识大脑（KOS），生成时可以**按需检索知识库**，给跨项目进展、某个发件人/公司的背景补充上下文，让周报、月报更有"连贯叙事"。这是可选增强，关着也能正常生成。

## 常见疑问

- **开了开关，第二天没看到？** 确认两层开关都开了（总开关 + 该 agent 在 Agents 页里也启用）；想立刻验证就用 **Run now**。
- **某天没什么重要邮件？** 内容会是"空"态（如"昨天无需特别关注的邮件"），这是正常的。
- **措辞想改？** 进该 agent 的配置面板改提示词，下次生成即生效。
