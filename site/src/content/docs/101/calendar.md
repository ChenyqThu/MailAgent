MailAgent 的日历把三类日程聚合到一张表：**邮箱日历**（Outlook / Exchange 上的日程，包括邮件里收到的会议邀请）、**事项日历**（[事项](/101/matters/)的截止时间与行动项排期）、**Agent 日历**（自定义 Agent 的定时任务与报告排程）。三个来源可以分别显示或隐藏，不想看事项截止的时候关掉就好。

## 自动识别会议邀请

这件事默认就在做，无需任何配置：当一封邮件带着 iCalendar（.ics）会议邀请时，MailAgent 会解析它，自动在日历里创建对应的事件，并把它和原邮件关联起来。

之后点开这个事件，就能看到会议时间、地点、组织者、与会者名单，点会议链接在浏览器里打开 Teams / Zoom，点「关联邮件」直接跳回那封邀请邮件。

## 打开完整日历同步（可选）

光靠邮件邀请，看不到你在 Outlook 里直接创建的会议，也看不到共享日历。要让 MailAgent 显示 Outlook 上的全部日程，需要打开 CalDAV 同步——首启向导或[应用内首次配置](/101/onboarding/)里可以开启。打开后，后台每隔约 60 秒检查一次日历变化。默认同步窗口是过去 30 天到未来 180 天，足够日常查看。

:::note[同步可能有最多 1 小时延迟]
受 DavMail 的技术限制，MailAgent 不总能即时感知到日历变化，最坏情况下你在 Outlook 改的日程要等约 1 小时才同步过来。等不及就点工具栏的「同步」按钮手动拉一次。
:::

:::note[EWS 关停提醒]
日历同步经 DavMail 通过 EWS 桥接 Exchange。微软计划自 **2026-10-01** 起默认阻断 EWS，届时 DavMail 当前路径将不可用。迁移方案详见 [`roadmap-post-cutover.md`](https://github.com/ChenyqThu/MailAgent/blob/main/docs/reference/architecture/roadmap-post-cutover.md) §5.1。
:::

## 视图

工具栏右侧可以切换视图：

| 视图 | 看什么 |
|---|---|
| 今日 | 单日 24 小时时间线，一眼看今天 |
| 周（默认） | 7 列 × 24 小时，看本周整体安排 |
| 月 | 每周一行的整月网格，跨天事件用色带堆叠 |
| Agenda（列表） | 未来 14 天，按日分组的紧凑列表 |
| 定期邀请 | 列出所有重复性会议，决定哪些要退订 |

工具栏中间用 `←` `→` 翻日期，`T` 回到今天；右侧有「同步」按钮和上次同步时间提示。

### 看懂事件的状态

事件的视觉状态由形状而不是单纯的透明度区分，工具栏有图例：

| 状态 | 视觉 |
|---|---|
| 已接受 / 已确认 | 正常显示 |
| 暂定 | 斜纹填充 |
| 待回复 | 空心描边 |
| 已拒绝 | 删除线 + 灰 |
| 已取消 | 删除线 + 深灰 |

## 拖拽改期与改时长

在周视图或日视图里直接拖动一个事件块可以改期，拖动事件块的上下边缘可以改时长——起拖有 4px 阈值防误触，拖动按 15 分钟吸附，拖动中按 `Escape` 就地回弹。松手后有 **5 秒撤销窗口**，窗口内点「撤销」，请求根本不会发往服务器；超过 5 秒才真正经 CalDAV 写回 Exchange。

## 时间冲突标记

邮箱日程之间的时间冲突会被标记出来，日视图、周视图、议程行与事件详情抽屉里都能看到「时间冲突」提示。

## 接受 / 拒绝 / 新建 / 编辑会议

点开任意事件，右侧会滑出详情抽屉。在抽屉里可以：

- **回复邀请**：点「接受」/「暂定」/「拒绝」，MailAgent 会向组织者发出标准的会议回复邮件（iTIP REPLY），这个操作不可撤回，会先弹一次确认。
- **编辑**或**删除**：如果这个会议是你自己组织的（别人组织的会议只能改你自己的回复状态）；删除同样有 5 秒撤销窗口。
- 点**会议链接**在浏览器外打开 Teams / Zoom，点**关联邮件**跳回对应的邀请邮件。

工具栏的「新建」可以从零创建一个会议，收件人（与会者）输入框接入通讯录补全。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `G` 然后 `D` / `W` / `M` / `A` / `R` | 切换 日 / 周 / 月 / Agenda / 定期邀请 |
| `T` | 回到今天 |
| `←` `→` | 翻日期 |
| `⌘R` | 同步 |
| `N` | 新建事件 |
| `J` / `K` | 下一个 / 上一个事件 |
| `Enter` | 打开选中的事件 |
| `Esc` | 关闭抽屉 |
| `?` | 查看全部快捷键 |

## 会进 Notion 吗（可选）

会议事件首先存在 MailAgent 本地数据库，若启用了 Notion 镜像，也会同步到 Notion 日历数据库。

## Windows 版的差异

Windows 上如果使用本机 Outlook 邮件后端（不经 DavMail），日历功能暂不提供——这是本机 Outlook 后端目前的已知限制，不是配置问题。想要日历功能，Windows 上需要改用 DavMail 后端。

## 常见疑问

- **改了 Outlook 的会议，MailAgent 没更新？** 同步最多有约 1 小时延迟，手动点「同步」立刻拉一次。
- **同步按钮变灰、显示报错？** 多半是 DavMail 连接出了问题，参见[故障排查](/101/troubleshooting/)。
- **想看的会议不在窗口里？** 默认只同步过去 30 天到未来 180 天，可以在设置里调整同步窗口。
